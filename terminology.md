# Terminology

> ⭐ "The beginning of wisdom is the definition of terms." -- Socrates

It's easy to get lost in conversations when you aren't aware of industry specific terminology, especially in the world of IT. This is just a basic set of words that I believe anyone working in IT should have an understanding of.

|Term| Definition |
|:--:|------------|
|**Algorithm**| A set of steps, or instructions, used to complete a specific task.|
|**API**| Application Programming Interface, a set of actions defined by a system or program. Other programs typically use APIs to retreive data, or perform some other action. The program using the API does NOT care how the API is implemented.|
|**Bug**| An error, flaw, or fault in a computer program or system that causes it to produce an incorrect or unexpected result, or to behave in unintended ways.|
|**Bit**| Binary digit, a basic unit of information using computer. One of two values (0 or 1)|
|**Byte**| A unit of digital information that consists of 8 Bits. Often used to encode a single character of text in a computer, thus making it the smallest adderessable unit of memory in most architectures|
|**ASCII**| American Standard Code for Information Interchange, assigns numerical values (0 to 127) to English language letters, numbers, punctuation, and control commands so computers can understand and display them|
|**Data Structures**| A specialized format of organizing, storing, and managing data in a computer's memory so that it can be accessed and used efficiently|
|**Arrays**| A fundamental data structure that stores a collection of elements contiguously in memory, usually of the same type, in a fixed-size and ordered sequence|
|**Big-O Notation**| A mathematical shorthand used in computer science to describe how an algorithm's performance (execution time or memory usage) scales as the size of the input data grows|
|**Compiler**| A computer program that translates code from within one programming language into another programming language, usually translating from a high level human-readable language (C++, Python, Java, etc) into a low-level language like machine code or bytecode that a computer's CPU can directly execute|
|**Cookies**| A small text file of information that a website's server generates and sends to your web browser and is stored locally on your device. Relevant cookies are attached to any future requests a user makes to the web server and helps inform websites about the user to personalize their experience|
|**Cache**| A high-speed, temporary storage area that holds frequently accessed data or files so they can be retrieved faster. It allows systems to bypass slower primary storage by keeping copies of data closer to the point of need|
|**Debugger**| A tool that allows developers to pause program execution via breakpoints, inspect system memory, and trace code execution line-by-line in real time to locate and fix bugs|
|**Executable**| A computer file, program, or set of instructions containing machine code or binary istructions that is ready to be opened and ran by your computer|
|**Garbage Collector**| A form of automatic memory management that works by scanning a memory allocated by the program, identifies objects that are no longer needed, and attempts to reclaim that memory. It was introduced to simplify manual memory management and minimize potential memory leaks|
|**IDE**| Integrated Development Environment, a software application that provides a comprehensive and centralized workspace to write, test, and debug code. Usually bundled with a text editor, compiler/interpreter, and debugger along with other tools into one easy-to-use interface|
|**Machine Code**| The fundamental language of computers, it consists of raw binary digits—a sequence of 1s and 0s—that a computer's CPU can execute diractly without any translation, it's the lowest level of software|
|**OOP**| Object-Oriented Programming, a software design approach based on the concept of objects, which groups related data (attributes, or properties) and actions (functions, or methods) and makes them reusable leading to code that is cleaner and easier to scale|
|**Open Source**| Refers to software where the underlying source code is made publicly available for anyone to view, modify, distribute, and enhance|
|**Pair Programming**| A technique where two programmers work together at one workstation. One developer writes the code while the other observes and reviews the code. The developers can switch roles at any point, but the idea is to help each other find a solution because there's likely some overlap in the code you're working on|
|**Recursion**| The process of a concept or function calling itself within its own definition. It allows complex problems to be broken down into simpler, self-similar sub-problems, but be careful as recursive solutions in programming can cause stack overflow exceptions|
|**Virtual Machine**| A software-defined computer that emulates a physical hardware system, essentially a virtual environment that has its own CPU, memory, and storage allocated to it and runs its own operating system and applications entirely isolated from the physical "host" machine. Due to its idependent behavior, you can run multiple VMs on a single physical device
|**Web Crawler**| An automated software program that systematically browses the internet primarily for the purpose of downloading and cataloging web page content so digital systems can analyze, organize, and index the vast information on the web|
|**IP Address**| Internet Protocol address, this is a unique numerical label assigned to devices connected to a computer network, best way to think of an IP address is like a physical mailing address|
|**DNS**| Domain Name System, a naming system for computers and services connected to the internet, essentially the internet's equivalent of a phone book. It acts as a directory that translates human-friendly website names (google.com) into numerical machine-readable IP addresses (like 192.168.1.1)|
|**Version Control**| The systematic practice of tracking and managing changes to files over time by recording exactly what edits were made, when they were made, and who made them, allowing you to easily revert to earlier versions if mistakes occur|
|**Exception Handling**| A programming mechanism used to manage runtime errors and unexpected events gracefully, rather than a program crashing abruptly when an issue occurs. This allows the application to detect the problem, execute fallback code, and conntinue running smoothly|
|**Virtual Private Network**| A VPN is a service that creates a secure, encrypted digital "tunnel" between your device and the internet, allowing you to mask your IP address and scrambles your data, ensuring your online activites remain private from hackers, your Internet Service Provider (ISP), and other unauthorized third parties|
|**Command Line Interface**| A CLI is a text-based user interface used to interact with a computer's operating system or software, instead of clicking icons with a mouse as you would in a Graphical User Interface (GUI), you type specific text commands via a keyboard|
|**RDBMS**| A Relational Database Management System is software that stores, manages, and retrieves data using the relational model, which organizes information into interconnected tables of rows and columns|
|**SQL**| Structured Query Language the standard programming language used to interact with and manage data in relational databases|
|**Pull Request**| A software development method where a developer notifies their team that they have completed a code change. Usually created through a platform like Github, a pull request (PR) acts as a formal proposal to merge new code into the main project, allowing collaborators to review, discuss, and test the changes before they are finalized|
|**Code Review**| A software quality assurance process where developers systematically examine each other's source code before it is merged into the main codebase, typically done as a result of a pull request|
|**HTTP**| Hypertext Transfer Protocol is the foundational set of rules that allows web browsers and servers to communicate, it dictates how messages are formatted and transmitted across the internet, enabling you to load webpasges, images, and other resources|
|**JSON**| JavaScript Object Notation, a lightweight, text-based data format used to store and exchange structured data. Although derived from a subset of the JavaScript programming language, JSON is language-independent and can be used by virtually all modern programming evnironments, including Python, Java, and C++|
|**Scripting Language**| A type of programming language used to automate tasks or provide additional functionality within a specifc runtime environment. Unlike traditional programming languages that are often compiled into machine code before running, scripting languages are typically interpreted, meaning an interpreter program reads and executes the code line-by-line during runtime|
|**camelCase**| A naming convention where multiple words are combined into a single compound word without spaces or punctuation. The first word begins with a lowercase letter and each subsequent word begins with a capital letter creating a staggered, hump-like appearance similar to a camel's back|
|**snake_case**| A naming convention used in programming where spaces between workds are replace with underscores(_). All letters are typically converted to lowercase to improve the readability of compound words or phrases|
|**PascalCase**| A naming convention where the first letter of every compound word is capitalized, and all spaces and underscores are removed. This is similar to camel case with the only difference being the first letter of the first word is also capitalized|
|**Cloud Computing**| The on-demand delivery of computing services—including servers, data storage, databases, networking, and software—over the internet. Instead of buying and maintaining physical data centers or hard drives, you rent access to these resources from third-party providers, paying only for what you use|
|**Pointer**| A programming variable that stores the memory address of another data value or object, rather than storing the data itself. It "points" to the location of the data in the computer's memory|
|**Web Hosting**| A type of service that allows you to rent server space on the internet—because nobody will be able to see your website on localhost—to store your website's files (code, images, and text). Think of your domain name as your home address, and web hosting as the physical plot of land that your house sits on|
|**Pseudocode**| A step-by-step description of an algorithm or program's logic, written in plain language mixed with code-like structures. The purpose is to outline the logic of the algorithm or program at a high level to communicate and deepen human understanding before writing actual code|
|**Unit Testing**| A software development practice where the smallest testable parts of an application, called units, are isolated and verified for correctness. A "unit" typically refers to an individual function, method, or class|
|**Thread**| A single sequence stream within a process, or the smallest sequense of instructions that can be managed and executed by a CPU. There can be more than one thread running at a time which allows a program to perform multiple tasks at once|
|**Race Condition**| A software or system flaw where an application's outcome depends uncontrollably on the exact timing or sequence of events, it typically occurs when multiple processes(like 2 threads) attempt to read and modify shared data at the same time|
