# Terminology

> ⭐ "The beginning of wisdom is the definition of terms." -- Socrates

It's easy to get lost in conversations when you aren't aware of industry specific terminology, especially in the world of IT. This is just a basic set of words that I believe anyone working in IT should have an understanding of.

Algorithm
: A set of steps, or instructions, used to complete a specific task.

API
: Application Programming Interface, a set of actions defined by a system or program. Other programs typically use APIs to retreive data, or perform some other action. The program using the API does NOT care how the API is implemented.

Bug
: An error, flaw, or fault in a computer program or system that causes it to produce an incorrect or unexpected result, or to behave in unintended ways.

Bit
: Binary digit, a basic unit of information using computer. One of two values (0 or 1)

Byte
: A unit of digital information that most commonly consists of 8 Bits. Smallest adderessable unit of memory in most architectures
