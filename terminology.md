# Terminology

> ⭐ "The beginning of wisdom is the definition of terms." -- Socrates

It's easy to get lost in conversations when you aren't aware of industry specific terminology, especially in the world of IT. This is just a basic set of words that I believe anyone working in IT should have an understanding of.

**Algorithm**
: A set of steps, or instructions, used to complete a specific task.

**API**
: Application Programming Interface, a set of actions defined by a system or program. Other programs typically use APIs to retreive data, or perform some other action. The program using the API does NOT care how the API is implemented.

**Bug**
: An error, flaw, or fault in a computer program or system that causes it to produce an incorrect or unexpected result, or to behave in unintended ways.

**Bit**
: Binary digit, a basic unit of information using computer. One of two values (0 or 1)

**Byte**
: A unit of digital information that consists of 8 Bits. Often used to encode a single character of text in a computer, thus making it the smallest adderessable unit of memory in most architectures

**ASCII**
: American Standard Code for Information Interchange, assigns numerical values (0 to 127) to English language letters, numbers, punctuation, and control commands so computers can understand and display them

**Data Structures**
: A specialized format of organizing, storing, and managing data in a computer's memory so that it can be accessed and used efficiently

**Arrays**
: A fundamental data structure that stores a collection of elements contiguously in memory, usually of the same type, in a fixed-size and ordered sequence

**Big-O Notation**
: A mathematical shorthand used in computer science to describe how an algorithm's performance (execution time or memory usage) scales as the size of the input data grows

**Compiler**
: A computer program that translates code from within one programming language into another programming language, usually translating from a high level human-readable language (C++, Python, Java, etc) into a low-level language like machine code or bytecode that a computer's CPU can directly execute

**Cookies**
: A small text file of information that a website's server generates and sends to your web browser and is stored locally on your device. Relevant cookies are attached to any future requests a user makes to the web server and helps inform websites about the user to personalize their experience

**Cache**
: A high-speed, temporary storage area that holds frequently accessed data or files so they can be retrieved faster. It allows systems to bypass slower primary storage by keeping copies of data closer to the point of need

**Debugger**
: A tool that allows developers to pause program execution via breakpoints, inspect system memory, and trace code execution line-by-line in real time to locate and fix bugs

**Executable**
: A computer file, program, or set of instructions containing machine code or binary istructions that is ready to be opened and ran by your computer

**Garbage Collector**
: A form of automatic memory management that works by scanning a memory allocated by the program, identifies objects that are no longer needed, and attempts to reclaim that memory. It was introduced to simplify manual memory management and minimize potential memory leaks

**IDE**
: Integrated Development Environment, a software application that provides a comprehensive and centralized workspace to write, test, and debug code. Usually bundled with a text editor, compiler/interpreter, and debugger along with other tools into one easy-to-use interface

**Machine Code**
: The fundamental language of computers, it consists of raw binary digits—a sequence of 1s and 0s—that a computer's CPU can execute diractly without any translation, it's the lowest level of software

**OOP**
: Object-Oriented Programming, a software design approach based on the concept of objects, which groups related data (attributes, or properties) and actions (functions, or methods) and makes them reusable leading to code that is cleaner and easier to scale

**Open Source**
: refers to software where the underlying source code is made publicly available for anyone to view, modify, distribute, and enhance

**Pair Programming**
: A technique where two programmers work together at one workstation. One developer writes the code while the other observes and reviews the code. The developers can switch roles at any point, but the idea is to help each other find a solution because there's likely some overlap in the code you're working on
